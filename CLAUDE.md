# hmmwv.ai

Next.js (App Router, TypeScript) static reference site built from a scanned Humvee book. Phase 0 only: no server, no database.

## Run
npm install && npm run dev   (http://localhost:3000)
npm run build                (static export to /out)

## Rules
- Content comes from /data/*.json. Do not hand-edit them. Read data/DATA-README.md first.
- Every image has an ID (p127-img01) and a credit. Always render the credit beside the image.
- Table values stay as printed in the book, typos included. Repair only at render time.
- Style: paper ground, olive and rust accents, Barlow Condensed headings, IBM Plex body. No em dashes in copy.
- Remove `output: "export"` in next.config.mjs when adding server features (forum, Supabase, Clerk).

## Technical manuals
/manuals/ lists manuals; each manual has a landing page (cover, PDF, contents), one reference page per paragraph or appendix (parts manuals like TM 9-2815-237-34P: one per work package, plate plus parts list, with the cross-reference indexes linking to them), and its interactive procedures under /manuals/<tm>/procedures/<slug>/. Content comes from data/manuals/<tm>.json, generated by scripts/import_manual.py from a capture-technical-manual output (also copies figures, table scans, cover and the renamed PDF to public/manuals/<tm>/). Do not hand-edit it; re-run the importer (`--id <tm>` when the capture folder is not named after the manual). Cover details (number, title, date) live in lib/manuals.ts. Old /procedures/ URLs redirect in vercel.json. Procedures come from data/manuals/<tm>-procedures.json (generated by scripts/build_procedures.py, one per lettered subsection, several diagrams each; do not hand-edit) plus a few hand-written ones in lib/procedures.ts.

## Manual capture kit
tools/capture-kit/ is the pipeline that turns a text-layer manual PDF into the capture that scripts/import_manual.py reads (page text, figures with callout keys, transcribed tables, review list). A copy also lives in the claude.ai Project "HMMWV.ai" as capture-kit/kit.txt. To capture a new manual: read tools/capture-kit/ORCHESTRATION.md, run `python3 -I tools/capture-kit/run_capture.py <pdf> <workdir> all-scripts "<title>"`, run the agent stages it lists without stopping between them, then `... build`, then import with scripts/import_manual.py. Keep the work directory outside the repo. The kit is general; heading patterns in extract.py match US Army TM numbering.

## Diagrams from TM captures
scripts/tm_diagrams.py turns captured TM figures into traced SVGs and callout positions (VectorMagic hand-off, potrace fallback). See scripts/tmdiagrams/README.md. Python venv in .venv; work files in work/ (ignored). Reviewed callouts live in diagrams/<tm>/<id>.json (tracked; edit them by hand during review, never with prep --force).

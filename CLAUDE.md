# hmmwv.ai

Next.js (App Router, TypeScript) static reference site built from a scanned Humvee book. Phase 0 only: no server, no database.

## Run
npm install && npm run dev   (http://localhost:3000)
npm run build                (static export to /out)

## Rules
- Content comes from /data/*.json. Do not hand-edit them. Read data/DATA-README.md first.
- Every image has an ID (p127-img01) and a credit. Always render the credit beside the image.
- Table values stay as printed in the book, typos included. Repair only at render time.
- Style: paper ground, olive and rust accents, Barlow Condensed headings, IBM Plex body. No em dashes in copy.
- Remove `output: "export"` in next.config.mjs when adding server features (forum, Supabase, Clerk).

## Technical manuals
/manuals/ lists manuals; each manual has a landing page (cover, PDF, contents), one reference page per paragraph or appendix, and its interactive procedures under /manuals/<tm>/procedures/<slug>/. Content comes from data/manuals/<tm>.json, generated by scripts/import_manual.py from a capture-technical-manual output (also copies figures, table scans, cover and the renamed PDF to public/manuals/<tm>/). Do not hand-edit it; re-run the importer. Cover details (number, title, date) live in lib/manuals.ts. Old /procedures/ URLs redirect in vercel.json.

## Diagrams from TM captures
scripts/tm_diagrams.py turns captured TM figures into traced SVGs, callout positions and procedure drafts (VectorMagic hand-off, potrace fallback). See scripts/tmdiagrams/README.md. Python venv in .venv; work files in work/ (ignored).
